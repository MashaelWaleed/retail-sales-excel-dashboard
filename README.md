# retail-sales-excel-dashboard
📊 Interactive Multi-Branch Retail Sales Dashboard (Excel)

An end-to-end Business Intelligence and Data Analysis project built in Microsoft Excel using Power Query, Power Pivot (Data Modeling & DAX), and interactive PivotCharts & Slicers to analyze multi-branch retail sales performance across 2023–2024.

🎯 Project Overview

The goal of this project is to consolidate raw multi-year retail transaction records into a clean, automated reporting model and provide stakeholders with an executive dashboard to track revenue, customer reach, branch performance, brand popularity, and payment trends.

Key KPIs Tracked

Total Revenue: $974.7K

Total Unique Customers: 638

Reporting Period: 2023 – 2024

Coverage: 5 Retail Branches across multiple brands, product categories, and payment methods****
